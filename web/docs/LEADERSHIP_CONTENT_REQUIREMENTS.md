# Leadership page publication gate

The leadership route must not be indexable until every displayed profile has been approved.

Required information per person:

- Full public name and current role.
- A concise first-person-approved biography.
- Verified qualifications and relevant experience dates.
- Current training, governance or student-support responsibilities.
- An approved professional profile URL and photograph, if used.
- Written permission to publish the profile.

Experience totals, employer history and qualifications must match supporting documents. When at least two complete profiles are approved, add `/about/leadership/` to the SEO route registry, link it from `/about/`, prerender it and include `Person` structured data that exactly matches the visible profiles.
