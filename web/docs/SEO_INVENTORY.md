# SEO Inventory

Baseline date: 2026-09-08

Repository: centaur/web

Baseline source snapshot: commit 312bb35f, working tree already contained 21 user changes before this inventory was created.

## Scope and preservation rule

This document records the website baseline and its SEO behavior. The implementation updates below preserve the visual design and most existing English copy while correcting technical SEO and unsupported placement terminology.

The inventory is based on:

- The route registry in src/routes.js and src/seo/seoRoutes.js.
- The current prerendered HTML under build/client/.
- The current source files under src/.
- The deployment files under public/.
- The existing verification scripts under tools/.

Raw HTML counts below are diagnostic measurements from the current build/client output. They are not content-quality scores and do not authorize copy changes.

## Post-implementation state

The baseline sections below preserve the original audit record. The completed
implementation now has 26 indexable routes and 2 noindex documents (the branded
404 document and the editorial comparison draft), with 28 route documents in the
release package. It also includes the public blog index, career-guide and
resource clusters, India and selective regional pages, a central route/metadata
registry, contextual internal-link groups, route-specific JSON-LD validation,
generated robots and sitemap files, and the passing local `npm run seo:gate`
quality gate. The external production check is intentionally recorded separately
in `SEO_IMPLEMENTATION_REPORT.md`; the live domain currently does not match this
repository's finalized output.

## URL and hierarchy inventory

The current canonical URL policy is:

- HTTPS only.
- Non-www host: centaurcareers.in.
- Trailing slash on every public non-root canonical path.
- One canonical URL per route.
- Query strings are preserved through host/protocol redirects and are not represented in canonical URLs.
- No hash-based public route is present in the active route graph.

## Content-source and claim controls

The repository already identifies dist/assets/index-Dkrbbp0A.js as the approved original content source through src/content/verifiedClaims.js and docs/CLAIMS_EVIDENCE_POLICY.md.

The following content is evidence-sensitive and must not be rewritten, strengthened, or expanded during later SEO work without approval:

- Placement support and eligibility wording.
- Target CTC ranges and job outcomes.
- Student counts and placement counts.
- Hiring-partner/company references.
- Testimonials and student names.
- Leadership names, roles, experience, and email addresses.
- Training-partner identity and Lucknow address.
- Program duration, pricing, delivery modes, and eligibility terms.

Phase 1 records these dependencies only. It does not make a truth determination about them.

## Inventory conclusions

1. The public route set is finite, explicit, and already statically prerendered.
2. The current site has a usable SEO subsystem; later phases should improve validation and suitability rather than replace it.
3. The main technical unknowns are deployed behavior, production-origin safety, CDN/WAF behavior, and performance measurements.
4. The main content risks are evidence verification and preserving the exact approved meaning of existing English copy.
5. The public blog index is exposed through src/routes.js; published article and populated category routes are discovered from validated local JSON during the build. No account, login, or other private route is exposed through the public route graph.
6. No route should be added or renamed as part of Phase 1.
