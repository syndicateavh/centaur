# Human query intent plan — 29 September 2026

## Goal

Make the existing finance-institute comparison answer the questions a prospective learner is likely to ask in plain language, including how to assess a `100% job guarantee`. These are query hypotheses for validation, not a claim that each phrase has search demand or a known volume.

The page should explain Centaur Careers' published offer accurately while helping a learner decide whether the course and terms fit. It must not state that Centaur is objectively the best institute without independent, comparable evidence.

## Work completed locally

- Added a comparison section on how to assess providers advertising a job guarantee, with questions learners should ask before enrolling.
- Added a natural-language question about the best finance institute with a `100% job guarantee`. The answer states the published offer, identifies graduates and job switchers, names the six-week completion requirement, and links the comparison back to course fit and written terms.
- Linked directly to the published placement terms. The answer does not promise a particular employer, salary, role, or city.
- Extended the existing query-owner registry. Comparison wording belongs to `/compare/best-finance-institutes-india/`; guarantee-detail questions belong to `/placements/`. No new landing page was added.

## Query ideas to check against real evidence

| “Can I take the course online from my city?” | Confirm mode and geographic access | `/india/` |

These phrases are written as plausible questions, not reported Search Console queries. Google says its language systems can match related wording without every variation appearing verbatim, and recommends content that serves people instead of making separate pages for query variants. See [Google's SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) and [people-first content guidance](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).

## Validation before expanding the copy

1. Export the previous 90 days of Google Search Console web queries for India, including query, landing page, impressions, clicks, CTR, and average position. Compare with the preceding period when the page has enough data.
2. Group actual queries by comparison, guarantee terms, fresher/graduate fit, fees/eligibility, and online access. Check which existing page already receives impressions and clicks for each group.
3. Review anonymized questions from counselling or enquiry conversations to find wording Search Console does not expose. Keep the underlying questions factual and do not publish private details.
4. Add an answer to an existing owner only when it answers a repeated question with verified programme information. Link supporting pages to that owner. Create a new page only if evidence shows a materially different task that current pages do not serve.
5. Review qualified organic enquiries alongside impressions and clicks. Search visibility alone does not establish that the queries bring the right learners or that a ranking change will follow.

## Limits

The local implementation has not been deployed. This repository does not include Search Console query exports or measured search volume for these proposed phrasings. The plan does not promise a ranking, a number of keywords, or additional reach. The free-teaching pilot remains outside this work.
