## Result-led selection protocol

1. Publish the already-reviewed package, then record the actual production deployment date and inspect live response, canonical, robots, sitemap, and Search Console index status for each owner. An undiscovered or excluded URL needs an indexing diagnosis before a copy rewrite.
2. Export **two equal completed 28-day windows** from the same Search Console property, search type, country, device, and filters. Import both Queries and Pages dimensions. Record the exact period and filters; the CSV importer cannot verify UI filter settings by itself. The old branded/former-homepage workbook does not qualify.
3. Use the Pages export to shortlist owners with relevant impressions. For each shortlisted URL, apply that exact **Page filter in Search Console and export its Queries** for both windows. Separate sitewide Queries and Pages exports cannot prove a URL/query pair. Inspect the live India search result for intent, snippet, competing answer, and SERP feature before editing.
4. Match the same windows to **confirmed organic enquiries by landing page** from GA4/CRM. A CTA click or pageview is not a qualified enquiry. Record unknown outcomes as unknown.
5. For the five regional URLs, require page-filtered evidence and a sourced local learner need before adding detail. For a post overlap, require both URL series and a redirect plan before consolidation. For an industry update, require a final primary source and qualified review. Record a keep, revise, expand, or hold decision with URL, query, evidence, owner, edit, and next review date.
